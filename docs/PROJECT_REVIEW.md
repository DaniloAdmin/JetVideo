# Аудит и план доработки · 20 ноября 2026

## Исходное состояние

В рабочей папке находились прежний отдельный бот и объединённая JOJO Studio 4.1. За основу взята последняя: Python/Tkinter, тёмный интерфейс, Buffer GraphQL, Cloudflare R2 через boto3, несколько профилей, сериализованный WATCH, атомарная запись истории, защита от повреждённого JSON и блокировка workspace. Монтаж уже поддерживал несколько вставок со стоп-кадрами и передачу результатов в ready. Имелись 67 локальных тестов, PyInstaller и Inno Setup.

Основная логика сохранена. Исходные приложения, видео, настройки и история не заменялись. Публичная версия подготовлена отдельно.

## Найденные проблемы

1. После потери ответа createPost не сохранялось намерение отправки; R2-копия удалялась, хотя Buffer уже мог принять запрос. Возможны дубли и недоступный файл для принятого поста.
2. Принимались только числовые имена, для описания всегда требовались сезон/серия, стартовые шаблоны содержали частные настройки контента.
3. Не проверялось завершение внешнего копирования. Произвольные/пересекающиеся папки могли нарушать изоляцию профилей.
4. Монтажу не хватало координат, размера, общей прозрачности, пользовательской длительности, наложения поверх движения, переносимых шаблонов и отмены. Валидация вставок теряла часть параметров.
5. Сборщик автоматически скачивал FFmpeg и встраивал GPL-бинарники без комплекта конкретных лицензий/исходников. Зависимости задавались диапазонами; старые документы не подтверждали актуальную Windows-проверку.
6. В дереве присутствовали личные настройки, отчёты восстановления и скриншоты аккаунтов. Публиковать весь корневой каталог было нельзя.

## Выполненный план

- Добавлены долговременные состояния uploaded/submitting/uncertain, проверка по полному списку Buffer перед повтором, сохранение R2 при неопределённом исходе, запрет автоматического повтора, связывание истории с каналом, SHA-256 для одинаковых файлов.
- Поддержаны любые имена, нейтральный стартовый конфиг, filename-переменная, необязательные серии, пустые хештеги и предпросмотр.
- Добавлены проверка стабильности/Windows-дескриптора файла, атомарный импорт через временное имя, валидация и изоляция папок, их выбор в UI, удаление профиля без удаления данных.
- Сохранён прежний монтаж со стоп-кадром; добавлены независимые наложения, параметры расположения/времени/прозрачности, схема 9:16, PNG/JPEG, шаблоны и отмена процесса с очисткой незавершённого результата.
- Добавлены «О программе», скрытая до настройки донатная ссылка, локальный журнал с ротацией и маскированием известных ключей, удобная сверка Buffer без заполнения очереди.
- Подготовлены чистые исходники, пример .env, ignore-правила, сканер файлов/Git-истории, фиксированные зависимости, внешнее подключение FFmpeg, PyInstaller/Inno Setup, документация и материалы RC-релиза.

## Проверка API

Сверены официальные Buffer Authentication, Create Video Post, Hosting Media, Posts & Scheduling, Post Metrics и S3 compatibility R2. Сохранена актуальная структура createPost: один канал, automatic + customScheduled, dueAt UTC, публичный video URL и thumbnailOffset. Состояние sent используется как подтверждение публикации. Метрики оставлены только для официального личного доступа; отсутствующие значения не моделируются.

Ссылки на использованные страницы приведены в README и THIRD_PARTY_NOTICES. Ключи владельца для реальных отправок не использовались.

## Решения автора

Лицензия пока оставлена открытой. Рекомендована MIT, объяснены отличия от GPL-3.0; окончательный LICENSE не оформлен. Донатная ссылка отсутствует и не выдумывалась. Публикация репозитория/релиза и загрузка пользовательских видео не выполнялись.
