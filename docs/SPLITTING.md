# Нарезка видео · локальная версия 4.3

Откройте **«Монтаж и нарезка»** и выберите **«Нарезать на части»**. Исходники, баннеры и папка результата общие для обоих режимов. Параметры нарезки сохраняются между запусками.

1. Добавьте один или несколько длинных видео. Они обрабатываются в порядке списка.
2. Укажите длительность исходного фрагмента: `120`, `02:00` или `00:02:00` означают две минуты. Сохранять последний короткий остаток можно включить или отключить.
3. Задайте название: `часть {part}` даст `часть 1.mp4`, `часть 2.mp4` и далее. Начальный номер можно изменить, например на 41 для продолжения серии. Если введено только `часть`, номер добавится автоматически.
4. Выберите «Без баннеров», «Наложение баннеров» либо «Стоп-кадр с баннерами».
5. Выберите папку результата и нажмите «Начать нарезку». Прогресс и результат появляются на этой странице, подробности — в журнале редактора. «Отмена» удалит только текущий незавершённый результат; готовые части останутся.

## Пример

Исходник длиной 9 минут 30 секунд, длительность части `00:02:00`, начальный номер 1, шаблон `часть {part}`:

| Файл | Интервал исходника | Длина без стоп-кадров |
| --- | --- | --- |
| часть 1.mp4 | 00:00–02:00 | 2 минуты |
| часть 2.mp4 | 02:00–04:00 | 2 минуты |
| часть 3.mp4 | 04:00–06:00 | 2 минуты |
| часть 4.mp4 | 06:00–08:00 | 2 минуты |
| часть 5.mp4 | 08:00–09:30 | 1 минута 30 секунд |

При отключённом сохранении короткого остатка последний файл не создаётся. Исходник при этом остаётся целиком на диске.

## Баннер в каждой части

Выберите режим баннера и нажмите «Добавить баннер» в том же блоке. Настройте файл, время, длительность, положение, размер и прозрачность. Можно сохранить общий список баннеров как шаблон или загрузить свой.

Время относится **к началу каждой полученной части**. Баннер на `00:00:30` появится на 30-й секунде первой, второй и последующих частей. Если последний остаток короче времени появления, этот баннер будет пропущен в нём, а причина попадёт в журнал. Длительный баннер в режиме наложения обрезается концом части.

- **Наложение** сохраняет движение исходника, его звук и заданную длину части. Звук баннеров не добавляется. Для частей строго по две минуты используйте этот режим.
- **Стоп-кадр** использует прежнюю логику: исходник приостанавливается на время рекламы, затем продолжается. Поэтому часть из 2 минут исходника и 5 секунд рекламы будет длиться примерно 2 минуты 5 секунд. Звук баннера берётся из общих настроек монтажа.
- **Без баннеров** не требует наличия баннеров и не проверяет их файлы. Сохранённый список вставок остаётся для следующей обработки.

Все вставки при нарезке используют выбранный здесь режим. Их параметры положения, размера, времени, длительности и фона сохраняются. При обработке целого видео режим выбирается в каждой вставке.

## Названия, безопасность и ограничения

Доступны `{part}`, `{part:03d}` для номеров с нулями (`001`) и `{source}` для имени исходника без расширения. Нумерация продолжается по всему выбранному списку видео. В имени нельзя указывать папки и запрещённые символы Windows.

Если файл уже существует, он сохраняется: новая версия получает суффикс `_2`, `_3` и далее. Для продолжения прежней серии удобнее задать следующий свободный начальный номер. Имена вида `часть 1.mp4` распознаются публикационным модулем как номер части 1, совместимо с прежними числовыми именами. Не отправляйте разные серии с одинаковыми номерами из одного профиля без проверки истории.

JetVideo ищет точную границу и перекодирует каждую часть в MP4 / H.264 / AAC за один проход вместе с баннерами. Точность длительности ограничена видеокадрами и блоками аудиокодека. Скорость зависит от компьютера, исходного формата и качества, указанного в «Настройки».

В комплектном ZIP FFmpeg и FFprobe обнаруживаются автоматически в папке `tools`. Исходники остаются на месте. «Передать в публикации» копирует готовые части в `ready` выбранного аккаунта. Публикации запускаются отдельно из одноимённого раздела.
